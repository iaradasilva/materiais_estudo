Plataforma iSUS

A plataforma iSUS é uma ferramenta desenvolvida para facilitar a extração, download e análise dos dados disponibilizados pelo DATASUS...

  • Acesso direto às bases de dados de saúde pública.
  • Download simplificado de microdados para análise.
  • Integração rápida com rotinas no R / Python.

Como Baixar os Dados no R com o Pacote microdatasus

Para automatizar o download de microdados do DATASUS diretamente no R (como SIM, SINASC, SIH e SIA), utilize o pacote microdatasus:

# Instalação do pacote microdatasus via GitHub
if (!require("remotes")) install.packages("remotes")
remotes::install_github("rfsaldanha/microdatasus")

# Carregar a biblioteca
library(microdatasus)

# Exemplo: Fazer o download dos dados do Sistema de Informação sobre Mortalidade (SIM)
dados_sim <- fetch_datasus(
  year_start = 2022, 
  year_end = 2022, 
  uf = "SP", 
  information_system = "SIM-DO"
)

# Processar e limpar as variáveis
dados_limpos <- process_sim(dados_sim)

# Visualizar as primeiras linhas
head(dados_limpos)
💡 Dica de Pesquisa: O pacote microdatasus padroniza automaticamente os rótulos de variáveis e dados categóricos, facilitando a aplicação direta de modelos estatísticos.
