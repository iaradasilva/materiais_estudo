Plataforma iSUS

A plataforma iSUS é uma ferramenta desenvolvida para facilitar a extração, download e análise dos dados disponibilizados pelo DATASUS...

  • Acesso direto às bases de dados de saúde pública.
  • Download simplificado de microdados para análise.
  • Integração rápida com rotinas no R / Python.

Como Baixar os Dados no R com o Pacote microdatasus

Para automatizar o download de microdados do DATASUS diretamente no R (como SIM, SINASC, SIH e SIA), utilize o pacote microdatasus:

# 1. Instalar o pacote microdatasus do GitHub (caso não tenha)
if (!require("devtools")) install.packages("devtools")
devtools::install_github("rsuassuna/microdatasus")

# 2. Carregar o pacote
library(microdatasus)

# 3. Exemplo: Baixar dados do Sistema de Informações sobre Mortalidade (SIM)
dados_sim <- fetch_datasus(
  year = 2022, 
  uf = "SP", 
  information_system = "SIM-DO"
)

# 4. Processar e limpar os dados
dados_sim_limpos <- process_sim(dados_sim)

# 5. Salvar localmente em TXT/CSV
write.csv(dados_sim_limpos, "data/dados_datasus_sim.txt", row.names = FALSE)
cat("Dados do DATASUS baixados com sucesso!")
📂 Acesso Direto ao Arquivo TXT:
Você também pode ler um arquivo pré-processado diretamente do repositório utilizando: 
dados <- read.csv("https://raw.githubusercontent.com/iaradasilva/curso_dados/main/data/pacientes.txt")
