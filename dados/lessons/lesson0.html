Plataforma EasySUS

O EasySUS é um software de pesquisa desenvolvido pelo Mestre Jorge Armando Piscoya Santibañez para facilitar a recuperação, o processamento e a análise exploratória de dados administrativos hospitalares provenientes do Sistema Único de Saúde (SUS) do Brasil.

Ele oferece uma interface web multilíngue pela qual pesquisadores e profissionais de saúde pública podem identificar conjuntos de dados oficiais do Sistema de Informação Hospitalar (SIH/SUS) disponibilizados pelo DATASUS, baixar arquivos .dbc, convertê-los em arquivos .csv prontos para análise, aplicar filtros baseados em municípios e códigos CID-10 (ICD-10), além de gerar resumos e visualizações interativas.

Ao integrar a aquisição, conversão, filtragem e exploração de dados em um único fluxo de trabalho, o EasySUS reduz barreiras técnicas ao uso de dados de saúde pública brasileira, mantendo ao mesmo tempo a rastreabilidade até a fonte oficial dos dados.

  • Identificação e download direto de arquivos oficiais (.dbc) do SIH/SUS (DATASUS).
  • Conversão automatizada para arquivos .csv prontos para análise.
  • Filtragem por municípios e códigos CID-10 (ICD-10) com resumos e visualizações interativas.
  • Integração rápida com rotinas de análise estatística no R e Python.

Como Baixar os Dados no R com o Pacote microdatasus

Caso queira automatizar o download de microdados do DATASUS diretamente via script no R (como SIM, SINASC, SIH e SIA), utilize o pacote microdatasus:

# 1. Instalar o pacote microdatasus do GitHub (caso não tenha)
if (!require("devtools")) install.packages("devtools")
devtools::install_github("rsuassuna/microdatasus")

# 2. Carregar o pacote
library(microdatasus)

# 3. Exemplo: Baixar dados do Sistema de Informações sobre Mortalidade (SIM)
dados_sim <- fetch_datasus(
  year = 2022, 
  uf = "SP", 
  information_system = "SIM-DO"
)

# 4. Processar e limpar os dados
dados_sim_limpos <- process_sim(dados_sim)

# 5. Salvar localmente em TXT/CSV
write.csv(dados_sim_limpos, "data/dados_datasus_sim.txt", row.names = FALSE)
cat("Dados do DATASUS baixados com sucesso!")
📂 Acesso Direto ao Arquivo TXT:
Você também pode ler um arquivo pré-processado diretamente do repositório utilizando: 
dados <- read.csv("https://raw.githubusercontent.com/iaradasilva/curso_dados/main/data/pacientes.txt")
