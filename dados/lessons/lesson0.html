Plataforma iSUS

A plataforma iSUS é uma ferramenta desenvolvida para facilitar a extração, download e análise dos dados disponibilizados pelo DATASUS (Sistema Único de Saúde).

  • Acesso direto às bases de dados de saúde pública do Brasil.
  • Download simplificado de microdados epidemiológicos para análise.
  • Integração rápida e automatizada com rotinas em R e Python.
💡 Dica de Extração: Utilize os filtros de busca da plataforma para extrair arquivos nos formatos nativos ou converta para .csv/.parquet para análises estatísticas em larga escala.

Como Baixar os Dados no R com o Pacote microdatasus

Para automatizar a extração dos microdados do DATASUS (como SIM, SINASC, SIH e SIA) diretamente no ambiente do R, utilizamos o pacote microdatasus:

# Instalação do pacote microdatasus via GitHub
if (!require("remotes")) install.packages("remotes")
remotes::install_github("rfsaldanha/microdatasus")

# Carregar a biblioteca
library(microdatasus)

# Exemplo: Download dos dados do Sistema de Informação sobre Mortalidade (SIM)
dados_sim <- fetch_datasus(
  year_start = 2022, 
  year_end = 2022, 
  uf = "SP", 
  information_system = "SIM-DO"
)

# Processar e pré-limpar as variáveis
dados_limpos <- process_sim(dados_sim)

# Visualizar a estrutura das primeiras linhas
head(dados_limpos)
💡 Tratamento Automático: O pacote microdatasus padroniza automaticamente os rótulos de variáveis e dados categóricos, poupando tempo na fase de limpeza dos dados epidemiológicos.
