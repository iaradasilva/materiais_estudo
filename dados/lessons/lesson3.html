MÓDULO 04 • VISUALIZAÇÃO DOS DADOS

Visualização de Dados Aplicada à Saúde

A Visualização de Dados transforma números e tabelas em representações gráficas claras, facilitando a comunicação de achados epidemiológicos, padrões temporais, diferenças entre grupos e associações entre variáveis para equipes técnicas, gestores e leitores de artigos científicos.

Um bom gráfico em saúde não serve apenas para "enfeitar" o relatório: ele deve responder a uma pergunta objetiva, respeitar as escalas dos dados, evitar distorções visuais e destacar a informação principal sem excesso de ruído.

💡 Dica de Estudo: Antes de escolher cores ou temas elaborados, pergunte-se: "Qual comparação ou padrão quero que o leitor enxergue em 3 segundos?" Escolha o tipo de gráfico a partir dessa pergunta.

Boas Práticas na Construção de Gráficos

  • Escolha adequada ao tipo de variável: use barras ou colunas para categorias/contagens, linhas para séries temporais ou tendências ordenadas, boxplots/violinos para comparar distribuições entre grupos e dispersão para relação entre duas variáveis numéricas.
  • Cuidado com o eixo y e distorções: em gráficos de barras que representam contagens ou magnitudes a partir do zero, truncar o eixo y pode exagerar diferenças pequenas; já em boxplots ou séries temporais, o ajuste de escala deve ser informado claramente.
  • Cores com propósito: use cores distintas para separar categorias ou destacar um grupo de interesse, evitando paletas confusas e garantindo contraste legível.
  • Títulos, subtítulos, unidades e fonte: sempre inclua unidades de medida (ex.: dias, anos, casos por 100 mil hab., R$) e indique a origem dos dados (ex.: SIH/SUS via EasySUS ou Dados simulados).

Como um Gráfico é Construído em Camadas

Tanto no R base quanto no pacote ggplot2, é útil pensar o gráfico como uma soma de camadas: primeiro os dados e o mapeamento estético (quais variáveis vão nos eixos x e y, cor ou preenchimento), depois a camada geométrica (pontos, barras, linhas, caixas) e, por fim, rótulos, escalas e tema.

Exemplo Prático em R (Dados Simulados — Copiar e Colar)

Copie e cole o código abaixo no RStudio. Ele gera uma série mensal simulada de atendimentos/internações em saúde e produz gráficos de tendência temporal, comparação entre grupos e relação entre variáveis (usando ggplot2 se estiver instalado, com alternativa em R base):

# ==============================================================================
# 1. GERAR BASE SIMULADA MENSAL DE SAÚDE (PRONTO PARA RODAR)
# ==============================================================================
set.seed(2026)

meses <- seq.Date(from = as.Date("2024-01-01"), by = "month", length.out = 24)

dados_mensais <- data.frame(
  mes = rep(meses, times = 2),
  regiao = rep(c("Região Norte", "Região Sul"), each = length(meses)),
  internacoes = c(
    round(180 + seq_along(meses) * 2.2 + 25 * sin(seq_along(meses) * pi / 6) + rnorm(24, 0, 12)),
    round(240 + seq_along(meses) * 1.5 + 30 * sin(seq_along(meses) * pi / 6 + 1) + rnorm(24, 0, 14))
  ),
  tempo_medio_dias = round(c(
    runif(24, 3.8, 6.5),
    runif(24, 3.2, 5.8)
  ), 1)
)

# ==============================================================================
# 2. VISUALIZAÇÃO COM GGPLOT2 (SE INSTALADO) OU R BASE
# ==============================================================================
if (requireNamespace("ggplot2", quietly = TRUE)) {
  library(ggplot2)

  # (A) Série temporal comparando duas regiões
  g_linha <- ggplot(dados_mensais, aes(x = mes, y = internacoes, color = regiao)) +
    geom_line(linewidth = 1.1) +
    geom_point(size = 2) +
    labs(
      title = "Evolução Mensal de Internações por Região",
      subtitle = "Dados simulados para fins didáticos (24 meses)",
      x = "Mês de referência",
      y = "Número de internações",
      color = "Região"
    ) +
    theme_minimal()
  print(g_linha)

  # (B) Boxplot do tempo médio de internação por região
  g_box <- ggplot(dados_mensais, aes(x = regiao, y = tempo_medio_dias, fill = regiao)) +
    geom_boxplot(alpha = 0.75, show.legend = FALSE) +
    labs(
      title = "Tempo Médio de Internação por Região",
      x = "Região",
      y = "Tempo médio (dias)"
    ) +
    theme_minimal()
  print(g_box)

  # (C) Dispersão: tempo médio de internação vs. volume de internações
  g_disp <- ggplot(dados_mensais, aes(x = tempo_medio_dias, y = internacoes, color = regiao)) +
    geom_point(size = 2.5, alpha = 0.85) +
    geom_smooth(method = "lm", se = FALSE, linetype = "dashed") +
    labs(
      title = "Relação entre Tempo Médio e Volume de Internações",
      x = "Tempo médio de internação (dias)",
      y = "Número de internações",
      color = "Região"
    ) +
    theme_minimal()
  print(g_disp)

} else {
  # Alternativa direta em R base (não exige pacotes extras)
  sul <- subset(dados_mensais, regiao == "Região Sul")
  norte <- subset(dados_mensais, regiao == "Região Norte")

  plot(
    sul$mes, sul$internacoes,
    type = "o", col = "#10B981", pch = 19,
    ylim = range(dados_mensais$internacoes),
    main = "Evolução Mensal de Internações",
    xlab = "Mês", ylab = "Número de internações"
  )
  lines(norte$mes, norte$internacoes, type = "o", col = "#2563EB", pch = 17)
  legend("topleft", legend = c("Região Sul", "Região Norte"), col = c("#10B981", "#2563EB"), pch = c(19, 17))
}
⚠️ Atenção ao Comparar Populações Diferentes: Ao comparar regiões, municípios ou hospitais com tamanhos populacionais ou capacidades muito distintas, valores absolutos (como total de internações) podem refletir o tamanho da população/estrutura e não necessariamente maior risco ou gravidade. Quando possível, avalie também taxas ou proporções.
