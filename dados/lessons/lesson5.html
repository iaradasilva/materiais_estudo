Modelos de Regressão: do GLM ao GAM

Modelos de regressão permitem investigar e quantificar a relação entre uma variável resposta (desfecho em saúde, como número de internações, óbitos, custo ou tempo de permanência) e um conjunto de variáveis explicativas (covariáveis como tempo, temperatura, faixa etária, sexo ou políticas públicas), controlando fatores de confusão.

Enquanto a regressão linear clássica exige resposta contínua com erros normais e relação estritamente linear, dados reais da área da saúde costumam apresentar contagens discretas, assimetria acentuada, sobredispersão e efeitos não lineares (como ciclos sazonais ou curvas de risco por idade e temperatura). Para lidar com cada um desses cenários, evoluímos dos Modelos Lineares (LM) para os Modelos Lineares Generalizados (GLM) e, em seguida, para os Modelos Aditivos Generalizados (GAM).

💡 Dica de Estudo: Comece sempre pelo modelo mais simples e interpretável adequado ao tipo de desfecho (por exemplo, GLM de Poisson ou Binomial Negativa para contagens) e avance para o GAM quando houver evidência visual ou estatística de não linearidade ou padrão temporal/sazonal suave.

1. A Estrutura Teórica: do LM ao GLM e ao GAM

Regressão Linear Clássica (LM): modela diretamente a média condicional E[Y | X] = μ = β0 + β1·X1 + ... + βp·Xp, assumindo que os resíduos seguem distribuição Normal com variância constante. Se aplicada a contagens pequenas, pode prever valores negativos e violar a homocedasticidade.

Modelos Lineares Generalizados (GLM): generalizam a regressão linear para respostas não normais e relações não lineares por meio de três componentes bem definidos:

  • Componente aleatório: define a distribuição de probabilidade da variável resposta Y na família exponencial (Normal, Binomial, Poisson, Gama, entre outras, além da extensão Binomial Negativa para contagens com sobredispersão), determinando como a variância se relaciona com a média.
  • Componente sistemático (preditor linear): combina linearmente os parâmetros e covariáveis em η = β0 + β1·X1 + ... + βp·Xp + offset, onde o termo de offset (como log(população)) ajusta o tempo ou a população de exposição.
  • Função de ligação g(μ): conecta a média esperada μ = E[Y] ao preditor linear por meio de g(μ) = η. Em dados de contagem, utiliza-se a ligação logarítmica (log(μ) = η), o que garante valores preditos sempre positivos (μ = exp(η)) e efeitos multiplicativos na escala original.

Modelos Aditivos Generalizados (GAM): preservam a distribuição de probabilidade e a função de ligação dos GLMs, mas substituem ou complementam efeitos lineares rígidos por funções suaves não paramétricas (splines) estimadas a partir dos dados:

g(μ) = β0 + β1·X1 + ... + s1(Z1) + s2(Z2) + offset

Na prática, cada função suave s(Z) é construída a partir de bases de funções (splines) com penalização de curvatura, permitindo modelar curvas complexas — como sazonalidade anual, tendências de longo prazo ou resposta não linear à idade e à temperatura — sem impor previamente uma forma paramétrica rígida (linear, quadrática ou senoidal).

2. Como Escolher e Interpretar Cada Modelo na Prática

  • Interpretação dos coeficientes no GLM e GAM (ligação log): como log(μ) = β0 + β1·X1, exponenciar o coeficiente (IRR = exp(β1)) fornece a Razão de Taxas de Incidência (Incidence Rate Ratio). Por exemplo, se exp(β1) = 0,80, o grupo exposto apresenta uma redução de 20% na taxa esperada de eventos em relação ao grupo de referência, mantendo as demais variáveis constantes.
  • Uso obrigatório do offset(log(pop)) em taxas: ao incluir + offset(log(pop)), modelamos diretamente a taxa por habitante, mantendo a variável resposta como contagem inteira exigida pelas distribuições de Poisson e Binomial Negativa.
  • Poisson vs. Binomial Negativa: ajuste primeiro o modelo de Poisson e verifique a razão de dispersão (Pearson chi-square / gl residuais). Se ficar próxima de 1, a Poisson atende bem; se for bem maior que 1 (sobredispersão), os erros padrão da Poisson ficam subestimados e recomenda-se usar a Binomial Negativa.
  • Entendendo os termos suaves s(x) no GAM: no pacote mgcv, cada termo suave apresenta os graus de liberdade efetivos (edf): edf ≈ 1 indica efeito praticamente linear, enquanto edf > 2 indica curvatura não linear relevante (como ciclos sazonais ou curvas de risco por idade/temperatura).

3. Exemplo Prático em R: Comparando GLM Poisson, Binomial Negativa e GAM

Copie e cole o código abaixo no RStudio. Ele simula 36 meses de internações com sazonalidade e sobredispersão, ajusta os três modelos em sequência e compara o ajuste pelo AIC (quanto menor o AIC, melhor o equilíbrio entre ajuste e parcimônia):

# ==============================================================================
# 1. SIMULAR SÉRIE MENSAL DE CONTAGENS COM SAZONALIDADE (PRONTO PARA RODAR)
# ==============================================================================
set.seed(2026)
n_meses <- 36
t_idx <- 1:n_meses

# População de referência e indicador de intervenção/ampliação de cobertura
pop <- round(seq(80000, 92000, length.out = n_meses))
intervencao <- ifelse(t_idx >= 19, 1, 0)

# Efeito sazonal suave + tendência + intervenção (na escala log da taxa)
sazonalidade <- 0.28 * sin(2 * pi * t_idx / 12)
log_taxa <- log(18 / 10000) + 0.004 * t_idx - 0.22 * intervencao + sazonalidade

# Sobredispersão via efeito gama
mult_disp <- rgamma(n_meses, shape = 12, rate = 12)
mu_casos <- pop * exp(log_taxa) * mult_disp
casos <- rpois(n_meses, lambda = mu_casos)

dados_reg <- data.frame(
  mes = seq.Date(from = as.Date("2023-01-01"), by = "month", length.out = n_meses),
  tempo = t_idx,
  pop = pop,
  intervencao = factor(intervencao, labels = c("Pré", "Pós")),
  casos = casos,
  taxa_10k = (casos / pop) * 10000
)

# ==============================================================================
# 2. GLM DE POISSON COM OFFSET DE POPULAÇÃO
# ==============================================================================
mod_pois <- glm(
  casos ~ tempo + intervencao + offset(log(pop)),
  family = poisson(link = "log"),
  data = dados_reg
)

summary(mod_pois)

# Razão de taxas (IRR = Incidence Rate Ratio) e checagem de sobredispersão
irr_pois <- exp(coef(mod_pois))
disp_ratio <- sum(residuals(mod_pois, type = "pearson")^2) / df.residual(mod_pois)

cat("IRR estimados (GLM Poisson):\n")
print(round(irr_pois, 3))
cat("Razão de dispersão de Pearson:", round(disp_ratio, 2), "\n")
cat("AIC GLM Poisson:", round(AIC(mod_pois), 2), "\n\n")

# ==============================================================================
# 3. GLM BINOMIAL NEGATIVA (TRATANDO SOBREDISPERSÃO)
# ==============================================================================
if (requireNamespace("MASS", quietly = TRUE)) {
  mod_nb <- MASS::glm.nb(
    casos ~ tempo + intervencao + offset(log(pop)),
    data = dados_reg
  )
  cat("--- Resumo GLM Binomial Negativa ---\n")
  print(summary(mod_nb))
  cat("IRR (Binomial Negativa) e IC 95%:\n")
  print(round(exp(cbind(IRR = coef(mod_nb), confint(mod_nb))), 3))
  cat("AIC GLM Binomial Negativa:", round(AIC(mod_nb), 2), "\n\n")
}

# ==============================================================================
# 4. GAM COM TERMO SUAVE PARA SAZONALIDADE/TEMPO (PACOTE MGCV)
# ==============================================================================
if (requireNamespace("mgcv", quietly = TRUE)) {
  library(mgcv)

  # s(tempo, k = 12, bs = "cr") captura curvas não lineares/sazonais suaves
  mod_gam <- gam(
    casos ~ intervencao + s(tempo, k = 12, bs = "cr") + offset(log(pop)),
    family = nb(),
    data = dados_reg,
    method = "REML"
  )

  cat("--- Resumo GAM (mgcv) ---\n")
  print(summary(mod_gam))
  cat("AIC GAM (Binomial Negativa):", round(AIC(mod_gam), 2), "\n\n")

  # Diagnóstico dos resíduos e adequação do número de bases k
  par(mfrow = c(2, 2))
  gam.check(mod_gam)
  par(mfrow = c(1, 1))

  # Visualizar ajuste observado vs. estimado pelo GAM
  pred_taxa_10k <- (predict(mod_gam, type = "response") / dados_reg$pop) * 10000

  plot(
    dados_reg$mes, dados_reg$taxa_10k,
    type = "o", pch = 19, col = "#64748B",
    main = "Taxa Observada vs. Ajuste GAM (por 10 mil hab.)",
    xlab = "Mês", ylab = "Taxa por 10.000 hab."
  )
  lines(dados_reg$mes, pred_taxa_10k, col = "#10B981", lwd = 2.5)
  legend(
    "topleft",
    legend = c("Observado", "Ajuste GAM"),
    col = c("#64748B", "#10B981"),
    pch = c(19, NA), lty = c(1, 1), lwd = c(1, 2.5)
  )
}
⚠️ Atenção ao Overfitting e Diagnóstico de Resíduos: Em modelos GAM, aumentar demais a dimensão da base (k) pode fazer a curva acompanhar ruídos aleatórios em vez do padrão epidemiológico real. Sempre verifique o valor de k-index no gam.check(), compare o AIC entre os modelos candidatos e analise a autocorrelação dos resíduos em séries temporais.
