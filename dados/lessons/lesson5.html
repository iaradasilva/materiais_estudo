Modelos de Regressão: do GLM ao GAM

Modelos de regressão permitem modelar a relação entre uma variável resposta (desfecho em saúde) e uma ou mais variáveis explicativas (preditoras ou covariáveis), controlando possíveis fatores de confusão e quantificando associações, riscos ou taxas.

Enquanto a regressão linear clássica assume erro normal e relação linear na escala original, dados reais de saúde frequentemente envolvem contagens, taxas, proporções ou efeitos não lineares (como sazonalidade ao longo do ano ou curvas de risco por idade). É aí que entram os Modelos Lineares Generalizados (GLM) e os Modelos Aditivos Generalizados (GAM).

💡 Dica de Estudo: Comece pelo modelo mais simples e interpretável adequado ao tipo de desfecho (ex.: GLM de Poisson ou Binomial Negativa para contagens) e avance para o GAM quando houver evidência de não linearidade ou padrão temporal/sazonal suave.

Do Modelo Linear ao GLM e ao GAM

  • Regressão Linear Clássica (LM): modela a média condicional $\mathbb{E}[Y \mid X] = \beta_0 + \beta_1 X_1 + \dots$ com erros aproximadamente normais e variância constante.
  • Modelos Lineares Generalizados (GLM): estendem a regressão linear por meio de uma função de ligação $g(\mu_i)$ e uma distribuição da família exponencial (ex.: Poisson ou Binomial Negativa com ligação logarítmica para contagens, incluindo offset(log(pop)) para modelar taxas).
  • Modelos Aditivos Generalizados (GAM): substituem ou complementam termos lineares por funções suaves (splines) $s(X_j)$, permitindo capturar curvas não lineares (como ciclos sazonais ou efeitos não lineares de idade/temperatura) sem impor uma forma paramétrica rígida.

Exemplo Prático em R: GLM (Poisson / Binomial Negativa) e GAM

Copie e cole o código abaixo no RStudio. Ele simula uma série temporal de 36 meses de internações com sazonalidade e sobredispersão, ajusta um GLM de Poisson, verifica a dispersão, ajusta um GLM Binomial Negativo (via MASS::glm.nb, se disponível) e ajusta um GAM (via mgcv::gam, se disponível):

# ==============================================================================
# 1. SIMULAR SÉRIE MENSAL DE CONTAGENS COM SAZONALIDADE (PRONTO PARA RODAR)
# ==============================================================================
set.seed(2026)
n_meses <- 36
t_idx <- 1:n_meses

# População de referência e indicador de intervenção/melhora de cobertura
pop <- round(seq(80000, 92000, length.out = n_meses))
intervencao <- ifelse(t_idx >= 19, 1, 0)

# Efeito sazonal suave + tendência + intervenção (na escala log da taxa)
sazonalidade <- 0.28 * sin(2 * pi * t_idx / 12)
log_taxa <- log(18 / 10000) + 0.004 * t_idx - 0.22 * intervencao + sazonalidade

# Sobredispersão via efeito gama
mult_disp <- rgamma(n_meses, shape = 12, rate = 12)
mu_casos <- pop * exp(log_taxa) * mult_disp
casos <- rpois(n_meses, lambda = mu_casos)

dados_reg <- data.frame(
  mes = seq.Date(from = as.Date("2023-01-01"), by = "month", length.out = n_meses),
  tempo = t_idx,
  pop = pop,
  intervencao = factor(intervencao, labels = c("Pré", "Pós")),
  casos = casos,
  taxa_10k = (casos / pop) * 10000
)

# ==============================================================================
# 2. GLM DE POISSON COM OFFSET DE POPULAÇÃO
# ==============================================================================
mod_pois <- glm(
  casos ~ tempo + intervencao + offset(log(pop)),
  family = poisson(link = "log"),
  data = dados_reg
)

summary(mod_pois)

# Razão de taxas (IRR = Incidence Rate Ratio) e checagem de dispersão
irr_pois <- exp(coef(mod_pois))
disp_ratio <- sum(residuals(mod_pois, type = "pearson")^2) / df.residual(mod_pois)

cat("IRR estimados (GLM Poisson):\n")
print(round(irr_pois, 3))
cat("Razão de dispersão de Pearson:", round(disp_ratio, 2), "\n\n")

# ==============================================================================
# 3. GLM BINOMIAL NEGATIVA (SE O PACOTE MASS ESTIVER INSTALADO)
# ==============================================================================
if (requireNamespace("MASS", quietly = TRUE)) {
  mod_nb <- MASS::glm.nb(
    casos ~ tempo + intervencao + offset(log(pop)),
    data = dados_reg
  )
  cat("--- Resumo GLM Binomial Negativa ---\n")
  print(summary(mod_nb))
  cat("IRR (Binomial Negativa):\n")
  print(round(exp(coef(mod_nb)), 3))
}

# ==============================================================================
# 4. GAM COM TERMO SUAVE PARA SAZONALIDADE/TEMPO (SE MGCV ESTIVER INSTALADO)
# ==============================================================================
if (requireNamespace("mgcv", quietly = TRUE)) {
  library(mgcv)

  # s(tempo, k = 12, bs = "cr") captura curvas não lineares/sazonais suaves
  mod_gam <- gam(
    casos ~ intervencao + s(tempo, k = 12, bs = "cr") + offset(log(pop)),
    family = nb(),
    data = dados_reg,
    method = "REML"
  )

  cat("--- Resumo GAM (mgcv) ---\n")
  print(summary(mod_gam))

  # Visualizar ajuste observado vs. estimado pelo GAM
  pred_taxa_10k <- (predict(mod_gam, type = "response") / dados_reg$pop) * 10000

  plot(
    dados_reg$mes, dados_reg$taxa_10k,
    type = "o", pch = 19, col = "#64748B",
    main = "Taxa Observada vs. Ajuste GAM (por 10 mil hab.)",
    xlab = "Mês", ylab = "Taxa por 10.000 hab."
  )
  lines(dados_reg$mes, pred_taxa_10k, col = "#10B981", lwd = 2.5)
  legend(
    "topleft",
    legend = c("Observado", "Ajuste GAM"),
    col = c("#64748B", "#10B981"),
    pch = c(19, NA), lty = c(1, 1), lwd = c(1, 2.5)
  )
}
⚠️ Atenção ao Overfitting e à Interpretação: Em modelos GAM, aumentar demais o número de funções base (k) pode gerar curvas excessivamente flexíveis ("ruído" em vez de padrão real). Sempre inspecione o diagnóstico do modelo (como gam.check() no mgcv) e avalie se a complexidade extra faz sentido epidemiológico.
