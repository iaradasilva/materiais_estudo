Análise Exploratória de Dados

A Análise Exploratória de Dados (AED) é a etapa inicial fundamental para compreender a estrutura de uma base de dados em saúde, verificar tipos de variáveis, identificar valores ausentes (NA), detectar inconsistências ou valores extremos (outliers) e formular hipóteses antes da modelagem estatística.

Quando trabalhamos com dados clínicos, epidemiológicos ou hospitalares (como os obtidos via EasySUS), explorar bem os dados evita interpretações distorcidas e garante decisões mais seguras nas etapas seguintes.

💡 Dica de Estudo: Execute os comandos passo a passo no console ou script do RStudio e inspecione sempre a estrutura do objeto antes de calcular estatísticas ou gerar gráficos.

O que vamos explorar?

  • Estrutura e qualidade dos dados: dimensões da base, nomes e tipos de variáveis (numéricas, categóricas/fatores, datas) e ocorrência de valores faltantes (NA).
  • Tendência central e dispersão: compreensão inicial de Média, Mediana, Moda, Variância, Desvio Padrão e intervalos interquartis.
  • Distribuição e valores atípicos: identificação visual e numérica de assimetrias e outliers antes de avançar para gráficos e modelos.

Como Ler e Interpretar um Boxplot

O boxplot (ou diagrama de caixa) resume a distribuição de uma variável numérica em cinco elementos principais, facilitando comparar grupos (como sexos, faixas etárias ou tipos de atendimento) e enxergar assimetrias e valores discrepantes de forma rápida.

  • Mediana (linha central dentro da caixa): divide os dados ordenados ao meio (50% abaixo e 50% acima). É excelente para dados assimétricos, como tempo de permanência hospitalar.
  • Caixa (Q1 a Q3) e IIQ: a base da caixa é o 1º quartil (Q1, 25%) e o topo é o 3º quartil (Q3, 75%). A largura/altura da caixa representa o Intervalo Interquartil ($\text{IIQ} = Q_3 - Q_1$), onde ficam os 50% centrais das observações.
  • Hastes (whiskers): indicam a extensão dos dados dentro dos limites usuais (geralmente até $1,5 \times \text{IIQ}$ a partir de Q1 e Q3, sem ultrapassar os valores observados mais extremos dentro desse intervalo).
  • Outliers (pontos isolados além das hastes): valores muito distantes do restante da amostra. Em saúde, podem indicar casos clínicos atípicos, internações prolongadas ou erros de digitação/codificação que merecem investigação.
  • Assimetria na leitura: se a mediana estiver mais próxima de Q1 e houver mais pontos extremos para cima, há assimetria à direita (muito comum em custos e tempo de internação).

Exemplo Prático em R

Abaixo está um exemplo em R para inspecionar a base, calcular estatísticas resumidas e gerar um boxplot:

# 1. Carregar pacotes úteis para exploração e visualização
# install.packages(c("dplyr", "ggplot2"))
library(dplyr)
library(ggplot2)

# 2. Carregar conjunto de dados (ajuste o caminho conforme seu arquivo)
dados <- read.csv("data/dados_saude.csv", stringsAsFactors = FALSE)

# 3. Inspecionar estrutura, dimensões e primeiras linhas
glimpse(dados)
head(dados)
summary(dados)

# 4. Verificar quantidade de valores ausentes (NA) por coluna
colSums(is.na(dados))

# 5. Boxplot simples no R base (ex.: variável numerica 'tempo_internacao')
boxplot(
  dados$tempo_internacao,
  main = "Distribuição do Tempo de Internação",
  ylab = "Dias",
  col = "#10B981"
)

# 6. Boxplot comparando grupos com ggplot2 (ex.: por sexo ou categoria)
ggplot(dados, aes(x = sexo, y = tempo_internacao, fill = sexo)) +
  geom_boxplot(alpha = 0.7, outlier.color = "#EF4444") +
  labs(
    title = "Tempo de Internação por Grupo",
    x = "Grupo",
    y = "Tempo de internação (dias)"
  ) +
  theme_minimal()
⚠️ Atenção com Outliers e Dados Assimétricos: Em variáveis da saúde — como tempo de internação, custos hospitalares ou contagens — é comum haver valores extremos. A Média é sensível a esses valores; nesses casos, avalie também a Mediana e a amplitude interquartil. Nunca exclua um outlier automaticamente sem antes verificar se ele é um registro válido ou um erro de dado.
