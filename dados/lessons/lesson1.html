Análise Exploratória de Dados

A Análise Exploratória de Dados (AED) é a etapa inicial fundamental para compreender a estrutura de uma base de dados em saúde, verificar tipos de variáveis, identificar valores ausentes (NA), detectar inconsistências ou valores extremos (outliers) e formular hipóteses antes da modelagem estatística.

Quando trabalhamos com dados clínicos, epidemiológicos ou hospitalares (como os obtidos via EasySUS), explorar bem os dados evita interpretações distorcidas e garante decisões mais seguras nas etapas seguintes.

💡 Dica de Estudo: O exemplo prático desta lição já cria uma base fictícia em saúde direto no R — basta copiar, colar no RStudio e rodar para testar todos os gráficos sem precisar baixar arquivos externos.

O que vamos explorar?

  • Estrutura e qualidade dos dados: dimensões da base, nomes e tipos de variáveis (numéricas, categóricas/fatores) e ocorrência de valores faltantes (NA).
  • Tendência central e dispersão: compreensão inicial de Média, Mediana, Moda, Variância, Desvio Padrão e intervalos interquartis.
  • Gráficos exploratórios essenciais: frequências de categorias, formato da distribuição, comparação por grupos e dispersão entre variáveis numéricas.

Principais Gráficos da Análise Exploratória

Cada tipo de gráfico responde a uma pergunta diferente durante a exploração dos dados. Veja como eles se complementam:

  • Gráfico de Barras (Frequência): mostra a contagem ou proporção de observações em categorias discretas (ex.: sexo, faixa etária categorizada, grupo de diagnóstico). Diferente do histograma, há separação entre as barras porque as categorias não formam um eixo contínuo.
  • Histograma (Distribuição): agrupa uma variável numérica contínua em faixas (bins) para revelar o formato da distribuição — se é simétrica, concentrada em certos valores ou enviesada (com cauda longa à direita ou à esquerda).
  • Gráfico de Dispersão (Dispersão / Relação): plota pares de valores numéricos (X no eixo horizontal e Y no eixo vertical), permitindo observar tendência (crescente, decrescente ou ausente), agrupamentos e pontos fora do padrão.

Como Ler e Interpretar um Boxplot

O boxplot (ou diagrama de caixa) resume a distribuição de uma variável numérica em cinco elementos principais, facilitando comparar grupos (como sexos, faixas etárias ou tipos de atendimento) e enxergar assimetrias e valores discrepantes de forma rápida.

  • Mediana (linha central dentro da caixa): divide os dados ordenados ao meio (50% abaixo e 50% acima). É excelente para dados assimétricos, como tempo de permanência hospitalar.
  • Caixa (Q1 a Q3) e IIQ: a base da caixa é o 1º quartil (Q1, 25%) e o topo é o 3º quartil (Q3, 75%). A caixa representa o Intervalo Interquartil ($\text{IIQ} = Q_3 - Q_1$), onde ficam os 50% centrais das observações.
  • Hastes (whiskers): indicam a extensão dos dados dentro dos limites usuais (geralmente até $1,5 \times \text{IIQ}$ a partir de Q1 e Q3).
  • Outliers (pontos isolados além das hastes): valores muito distantes do restante da amostra. Em saúde, podem indicar casos clínicos atípicos, internações prolongadas ou erros de registro que merecem investigação.
  • Assimetria na leitura: se a mediana estiver mais próxima de Q1 e houver mais pontos extremos para cima, há assimetria à direita (muito comum em custos e tempo de internação).

Exemplo Prático em R (Dados Simulados — Copiar e Colar)

Copie e cole o código abaixo no seu editor do RStudio e execute linha por linha (ou todo o bloco) para ver a exploração de uma base fictícia de saúde com frequências, distribuição, boxplot e dispersão:

# ==============================================================================
# 1. CRIAR BASE DE DADOS FICTÍCIA EM SAÚDE (PRONTO PARA RODAR)
# ==============================================================================
set.seed(42)
n <- 200

idade <- round(rnorm(n, mean = 48, sd = 16))
idade <- pmax(1, pmin(95, idade)) # limita idades entre 1 e 95 anos

grupo_atendimento <- sample(
  c("Ambulatorial", "Emergência", "Internação"),
  size = n,
  replace = TRUE,
  prob = c(0.45, 0.35, 0.20)
)

# Tempo de internação / permanência (dias) com assimetria e alguns valores altos
dias_permanencia <- round(rlnorm(n, meanlog = log(4), sdlog = 0.75))

# Custo estimado (R$) crescendo com dias de permanência + variação aleatória
custo_reais <- round(dias_permanencia * 650 + rnorm(n, mean = 400, sd = 600))
custo_reais <- pmax(150, custo_reais)

dados_saude <- data.frame(
  id = 1:n,
  idade = idade,
  grupo_atendimento = factor(grupo_atendimento),
  dias_permanencia = dias_permanencia,
  custo_reais = custo_reais
)

# Inserir artificialmente alguns valores ausentes (NA) para treinar checagem
dados_saude$custo_reais[c(5, 37, 112)] <- NA

# ==============================================================================
# 2. INSPEÇÃO INICIAL E RESUMO
# ==============================================================================
str(dados_saude)
head(dados_saude)
summary(dados_saude)
colSums(is.na(dados_saude))

# ==============================================================================
# 3. GRÁFICOS EXPLORATÓRIOS (FREQUÊNCIA, DISTRIBUIÇÃO, BOXPLOT E DISPERSÃO)
# ==============================================================================

# (A) Frequência: gráfico de barras por grupo de atendimento
tab_grupo <- table(dados_saude$grupo_atendimento)
print(tab_grupo)
prop.table(tab_grupo) # proporções

barplot(
  tab_grupo,
  main = "Frequência por Tipo de Atendimento",
  xlab = "Tipo de Atendimento",
  ylab = "Número de Registros",
  col = c("#10B981", "#3B82F6", "#F59E0B")
)

# (B) Distribuição: histograma da idade
hist(
  dados_saude$idade,
  breaks = 12,
  main = "Distribuição da Idade dos Pacientes",
  xlab = "Idade (anos)",
  ylab = "Frequência",
  col = "#10B981",
  border = "white"
)

# (C) Comparação e quartis: boxplot dos dias de permanência por grupo
boxplot(
  dias_permanencia ~ grupo_atendimento,
  data = dados_saude,
  main = "Dias de Permanência por Tipo de Atendimento",
  xlab = "Tipo de Atendimento",
  ylab = "Dias de Permanência",
  col = c("#A7F3D0", "#BFDBFE", "#FDE68A")
)

# (D) Dispersão: relação entre dias de permanência e custo estimado
plot(
  dados_saude$dias_permanencia,
  dados_saude$custo_reais,
  main = "Dispersão: Dias de Permanência vs. Custo Estimado",
  xlab = "Dias de Permanência",
  ylab = "Custo Estimado (R$)",
  pch = 19,
  col = rgb(16/255, 185/255, 129/255, 0.7)
)
abline(lm(custo_reais ~ dias_permanencia, data = dados_saude), col = "#EF4444", lwd = 2)
⚠️ Atenção com Outliers e Dados Assimétricos: Em variáveis da saúde — como tempo de internação, custos hospitalares ou contagens — é comum haver valores extremos. A Média é sensível a esses valores; nesses casos, avalie também a Mediana e a amplitude interquartil. Nunca exclua um outlier automaticamente sem antes verificar se ele é um registro válido ou um erro de dado.
