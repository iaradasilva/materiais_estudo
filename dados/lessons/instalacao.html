O que é o Software R

O R é uma linguagem de programação e ambiente computacional gratuito, multiplataforma e de código aberto voltado para análise estatística, ciência de dados e visualização gráfica. Amplamente adotado na pesquisa científica e na saúde pública, o R permite reproduzir análises, manipular grandes bases de dados e aplicar desde técnicas descritivas até modelos estatísticos avançados.

Para tornar o trabalho mais intuitivo e produtivo, utilizamos o R em conjunto com o RStudio, um ambiente de desenvolvimento integrado (IDE) que organiza em uma única tela o editor de códigos, o console de execução, o ambiente de variáveis e a visualização de gráficos e tabelas.

Por que usar o R na Análise de Dados em Saúde?

  • Gratuito e de código aberto: sem custos de licença, funcionando em Windows, macOS e Linux.
  • Reprodutibilidade científica: todo o fluxo de limpeza, análise e geração de gráficos fica registrado em scripts.
  • Ecossistema de pacotes: milhares de extensões para manipulação de dados (como tidyverse e dplyr), visualização (ggplot2) e modelagem estatística.
  • Integração com dados públicos: leitura direta de arquivos .csv e .txt extraídos de plataformas como o EasySUS.

Links Oficiais para Download

Para utilizar o ambiente corretamente, instale primeiro o R e em seguida o RStudio Desktop:

1. Baixar o R (CRAN — Comprehensive R Archive Network):
Acesse a página oficial do projeto R e escolha a versão correspondente ao seu sistema operacional (Windows, macOS ou Linux):
https://cran.r-project.org/

2. Baixar o RStudio Desktop (Posit):
Após instalar o R, baixe a versão gratuita do RStudio Desktop:
https://posit.co/download/rstudio-desktop/

Checklist de Preparação para o Curso

  • Instalar o R e o RStudio Desktop antes dos dias 3 e 4 de dezembro.
  • Abrir o RStudio e verificar se o console inicializa sem mensagens de erro.
  • Criar uma pasta dedicada no computador para salvar os scripts e arquivos de dados das aulas práticas.
