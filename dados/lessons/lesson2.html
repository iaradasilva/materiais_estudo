MÓDULO 03 • ESTATÍSTICA DESCRITIVA

Estatística Descritiva Aplicada à Saúde

A Estatística Descritiva resume e organiza um conjunto de dados por meio de medidas numéricas e tabelas, permitindo comunicar de forma objetiva o comportamento de uma amostra ou população antes de testar hipóteses ou ajustar modelos.

Na área da saúde, resumir corretamente variáveis contínuas (como idade, pressão arterial, tempo de internação ou gastos hospitalares) e variáveis categóricas (como sexo, desfecho ou grupo de diagnóstico) é essencial para interpretar cenários clínicos e epidemiológicos sem distorções.

💡 Dica de Estudo: Sempre reporte mais de uma medida de resumo — por exemplo, média e desvio padrão quando a distribuição for aproximadamente simétrica, e mediana e intervalo interquartil (IIQ) quando houver assimetria ou valores extremos.

Medidas de Tendência Central e Posição

  • Média aritmética: soma de todos os valores dividida pelo número de observações. É sensível a valores muito altos ou muito baixos (outliers).
  • Mediana: valor central que separa a metade inferior da metade superior dos dados ordenados (50º percentil). É robusta frente a assimetrias e valores extremos.
  • Moda: valor ou categoria que ocorre com maior frequência no conjunto de dados — muito útil para variáveis categóricas ou discretas.
  • Quartis e percentis: dividem os dados ordenados em partes (por exemplo, $Q_1$ = 25%, $Q_2$ = mediana/50%, $Q_3$ = 75%).

Medidas de Dispersão (Variabilidade)

  • Amplitude total: diferença entre o valor máximo e o valor mínimo (max - min). Simples, mas sensível a extremos.
  • Variância e Desvio Padrão (DP): medem o quanto os valores se afastam, em média, da média aritmética. O desvio padrão volta para a mesma unidade da variável original (ex.: anos, dias, mg/dL).
  • Intervalo Interquartil ($\text{IIQ} = Q_3 - Q_1$): mede a dispersão dos 50% centrais dos dados; acompanha naturalmente a mediana em distribuições assimétricas.
  • Coeficiente de Variação ($\text{CV} = \frac{\text{DP}}{\text{Média}} \times 100\%$): útil para comparar a variabilidade relativa entre variáveis com escalas ou unidades diferentes.

Simetria vs. Assimetria: Quando Média e Mediana se Afastam?

Quando uma distribuição é simétrica, média e mediana ficam próximas. Quando há assimetria à direita (cauda longa para valores altos, muito comum em tempo de internação e custos em saúde), a média é puxada para cima em relação à mediana.

Exemplo Prático em R (Dados Simulados — Copiar e Colar)

Copie e cole o código abaixo no RStudio para calcular medidas de tendência central, dispersão e resumos por grupo em uma base simulada de saúde:

# ==============================================================================
# 1. BASE DE DADOS SIMULADA EM SAÚDE (PRONTO PARA RODAR)
# ==============================================================================
set.seed(123)
n <- 250

dados_clinicos <- data.frame(
  id = 1:n,
  sexo = factor(sample(c("Feminino", "Masculino"), n, replace = TRUE)),
  risco = factor(
    sample(c("Baixo", "Moderado", "Alto"), n, replace = TRUE, prob = c(0.5, 0.3, 0.2)),
    levels = c("Baixo", "Moderado", "Alto")
  ),
  idade = round(rnorm(n, mean = 52, sd = 14)),
  tempo_internacao = round(rlnorm(n, meanlog = log(3.5), sdlog = 0.7))
)

# ==============================================================================
# 2. MEDIDAS DE POSIÇÃO E DISPERSÃO (VARIÁVEL CONTÍNUA)
# ==============================================================================
x <- dados_clinicos$tempo_internacao

media_x <- mean(x)
mediana_x <- median(x)
dp_x <- sd(x)
var_x <- var(x)
iiq_x <- IQR(x)
quantis_x <- quantile(x, probs = c(0, 0.25, 0.5, 0.75, 1))
cv_x <- (dp_x / media_x) * 100

cat("Média:", round(media_x, 2), "\n")
cat("Mediana:", mediana_x, "\n")
cat("Desvio Padrão:", round(dp_x, 2), "\n")
cat("Variância:", round(var_x, 2), "\n")
cat("IIQ (Q3 - Q1):", iiq_x, "\n")
cat("Coeficiente de Variação (%):", round(cv_x, 1), "%\n")
print(quantis_x)

# ==============================================================================
# 3. FREQUÊNCIAS E RESUMO POR GRUPO
# ==============================================================================
# Frequência absoluta e relativa da variável categórica 'risco'
tab_risco <- table(dados_clinicos$risco)
prop_risco <- round(prop.table(tab_risco) * 100, 1)
cbind(Frequencia = tab_risco, Percentual = prop_risco)

# Estatísticas descritivas por nível de risco usando aggregate()
aggregate(
  tempo_internacao ~ risco,
  data = dados_clinicos,
  FUN = function(v) c(
    n = length(v),
    media = round(mean(v), 2),
    dp = round(sd(v), 2),
    mediana = median(v),
    iiq = IQR(v)
  )
)
⚠️ Atenção ao Interpretar Médias e Desvios Padrão: Um desvio padrão muito grande em relação à média (ou uma média bem acima da mediana) indica forte dispersão ou assimetria. Nesses casos, apresentar apenas a média pode esconder o comportamento típico da maioria dos pacientes.
