Análise Exploratória de Dados

A Análise Exploratória de Dados é a primeira etapa crítica de qualquer projeto de Ciência de Dados. Seu objetivo principal é entender a estrutura dos dados, identificar padrões e detectar anomalias antes de aplicar qualquer modelo estatístico.

💡 Dica de Estudo: Você pode acompanhar o código desta lição executando o notebook diretamente no Google Colab.

O que vamos aprender?

  • Entender as medidas de tendência central: Média, Mediana e Moda.
  • Calcular dispersão usando Variância e Desvio Padrão.
  • Visualizar distribuições de frequência com Histogramas e Boxplots.

Exemplo Prático em r

Abaixo está o código base para carregar um conjunto de dados e gerar um resumo estatístico rápido:

import pandas as pd
import numpy as np

# Carregar conjunto de dados
df = pd.read_csv("datasets/vendas.csv")

# Resumo estatístico completo
print(df.describe())
⚠️ Atenção com Outliers: A Média é altamente sensível a valores extremos. Quando seu dataset tiver discrepâncias grandes, prefira utilizar a Mediana.
