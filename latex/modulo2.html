MÓDULO 2 • FORMATAÇÃO

Formatação de Texto e Listas

Neste módulo você aprenderá a aplicar os estilos de texto mais comuns e a criar listas organizadas de forma simples no LaTeX.

1. Estilos de Fonte

No LaTeX, aplicamos estilos no texto utilizando comandos específicos:

\textbf{Este texto estará em negrito.}
\textit{Este texto estará em itálico.}
\underline{Este texto estará sublinhado.}
\texttt{Texto em estilo código (monoespaçado).}

2. Tamanho dos Textos

Você pode alterar o tamanho das fontes usando comandos declarativos:

{\small Texto pequeno}
{\large Texto grande}
{\Huge Texto muito grande}

3. Criando Listas

Existem dois tipos principais de ambientes para listas:

Listas Não Ordenadas (Marcadores)

\begin{itemize}
  \item Primeiro item
  \item Segundo item
  \item Terceiro item
\end{itemize}

Listas Ordenadas (Numeradas)

\begin{enumerate}
  \item Passo um
  \item Passo dois
  \item Passo três
\end{enumerate}
