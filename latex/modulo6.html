Criando um Trabalho com Múltiplos Arquivos (.tex)

Em trabalhos acadêmicos longos, é uma boa prática criar um arquivo .tex separado para cada seção (Introdução, Metodologia, Resultados, Conclusão) e importá-los no arquivo principal main.tex através do comando \input{}.

⚠️ REGRA DE OURO: Apenas o arquivo main.tex possui \documentclass, preâmbulo e o bloco \begin{document}...\end{document}. Os arquivos das seções contêm apenas o texto, começando direto com \section{...}.

Passo 1: Como criar os novos arquivos no Overleaf

  1. No painel esquerdo do Overleaf, clique no ícone de Novo Arquivo (folha com sinal de +).
  2. Crie 4 arquivos com os nomes exatos:
    • introducao.tex
    • metodologia.tex
    • resultados.tex
    • conclusao.tex
  3. Crie também o arquivo referencias.bib para as citações bibliográficas.

Passo 2: Conteúdo de cada arquivo secundário

Abra cada arquivo recém-criado e cole apenas o seu respetivo bloco de texto:

Ficheiro: introducao.tex

\section{Introdução}
Esta é a introdução do documento. Apresente o contexto do seu trabalho e os seus objetivos. 

Por exemplo: segundo Lamport \cite{lamport1994latex}, o uso do LaTeX facilita a escrita técnica. Outro clássico da área é o trabalho de Knuth \cite{knuth1984texbook}.

Ficheiro: metodologia.tex

\section{Metodologia}
Descreva nesta seção os materiais, métodos, procedimentos ou ferramentas computacionais utilizadas para a realização da pesquisa.

Ficheiro: resultados.tex

\section{Resultados e Discussão}
Apresente aqui os dados obtidos durante a pesquisa. Você pode incluir tabelas, gráficos, figuras ou equações para ilustrar os resultados.

Ficheiro: conclusao.tex

\section{Conclusão}
Sintetize as principais conclusões alcançadas, verifique se os objetivos foram atingidos e sugira trabalhos futuros.

Ficheiro: referencias.bib

@book{lamport1994latex,
  author    = {Leslie Lamport},
  title     = {LaTeX: A Document Preparation System},
  year      = {1994},
  publisher = {Addison-Wesley}
}

@book{knuth1984texbook,
  author    = {Donald E. Knuth},
  title     = {The TeXbook},
  year      = {1984},
  publisher = {Addison-Wesley}
}

Passo 3: Conectar tudo no arquivo principal (main.tex)

Agora, abra o seu arquivo main.tex e use o comando \input{nome-do-arquivo} para chamar cada uma das páginas organizadamente:

\documentclass[12pt, a4paper]{article}

% --- PACOTES BÁSICOS ---
\usepackage[utf8]{inputenc}    % Suporte para acentuação
\usepackage[brazil]{babel}     % Tradução automática para português
\usepackage[margin=2.5cm]{geometry} % Margens da página
\usepackage{natbib}              % Suporte a citações
\usepackage{graphicx}           %suporte para as figuras

% --- METADADOS DA CAPA ---
\title{\textbf{Título do Seu Trabalho: Subtítulo Explicativo}}
\author{Seu Nome Completo}
\date{\today}

\begin{document}

% --- 1. CAPA ---
\maketitle
\thispagestyle{empty}
\newpage

% --- 2. RESUMO ---
\pagenumbering{arabic}
\begin{abstract}
Este é o resumo do trabalho. Apresente aqui brevemente o objetivo da pesquisa, a metodologia empregada e os principais resultados obtidos.

\vspace{0.5cm}
\noindent \textbf{Palavras-chave:} LaTeX, Overleaf, Estrutura Modular, Multi-arquivos.
\end{abstract}

\newpage

% --- 3. INCLUSÃO DAS SEÇÕES (ARQUIVOS .TEX SEPARADOS) ---
\input{introducao}
\input{metodologia}
\input{resultados}
\input{conclusao}

% --- 4. REFERÊNCIAS BIBLIOGRÁFICAS ---
\bibliographystyle{plain}
\bibliography{referencias}

\end{document}
💡 Como o \input{} funciona: Na hora da compilação, o LaTeX pega o texto de cada arquivo secundário e "cola" exatamente onde o comando \input{} foi colocado. Isso evita erros e deixa seu projeto muito mais limpo!
