MÓDULO 5 • AUTOMAÇÃO

Gerenciamento de Referências com BibTeX

Automatize as citações e a lista bibliográfica do seu trabalho acadêmico sem precisar formatar manualmente cada referência.

1. O Arquivo .bib

Crie um arquivo separado chamado referencias.bib no seu projeto e adicione a estrutura das suas fontes:

@article{lamport1986,
  author = {Leslie Lamport},
  title = {LaTeX: A Document Preparation System},
  year = {1986},
  publisher = {Addison-Wesley}
}

2. Citando Referências no Texto

No seu documento principal (main.tex), utilize o comando \cite{chave} para citar qualquer obra cadastrada no seu arquivo .bib:

Segundo \cite{lamport1986}, o sistema simplifica a escrita científica.

% No final do arquivo para gerar a lista de referências:
\bibliographystyle{plain} % ou abntex2-alf para ABNT
\bibliography{referencias}
💡 Vantagem do BibTeX: O LaTeX lista apenas as obras que foram efetivamente citadas no texto, formatando tudo automaticamente em ordem alfabética ou numérica.
